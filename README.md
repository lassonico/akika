Sitio web oficial de **Akika**, una repostería artesanal familiar ubicada en **Palermo, Huila, Colombia**, especializada en postres saludables libres de azúcar refinada, gluten y harinas tradicionales.

## ✨ Características

- **Postres Sin Culpa** - Cupcakes, brownies y galletas elaborados con ingredientes nobles
- **100% Sin Gluten** - Hechos con harina de almendra
- **Sin Azúcar Refinada** - Endulzados con alulosa
- **Apto Keto y Paleo** - Bajo en carbohidratos netos
- **Compra Directa por WhatsApp** - Sistema de carrito integrado para pedidos rápidos
- **Diseño Responsivo** - Optimizado para móvil, tablet y escritorio
- **UX Moderna** - Animaciones suaves y navegación intuitiva

## 🚀 Instalación y Uso

1. Clona el repositorio:

```bash
git clone https://github.com/lassonico/akika.git
cd akika
```

2. Abre `index.html` en tu navegador web, o usa un servidor local:

```bash
# Con Python
python -m http.server 8000

# Con Node.js (npx)
npx serve .
```

3. Navega a `http://localhost:8000` para visualizar el sitio.

## 📲 Cómo Realizar un Pedido

1. Selecciona los productos desde el catálogo o agrega directamente al carrito
2. Ajusta las cantidades desde el carrito
3. Completa el formulario con tus datos (nombre, celular, modalidad de entrega, fecha)
4. Haz clic en "Enviar Pedido" para ser redirigido a WhatsApp con el resumen completo
5. Confirma tu pedido directamente con Akika por WhatsApp
